# Free SMS Reminders for iPhone

Automatic appointment SMS reminders using Apple Calendar, Shortcuts and Messages. Free, no subscription and no external service operated by this project.

Automatické SMS připomínky termínů pomocí Apple Kalendáře, Zkratek a Zpráv. Zdarma, bez předplatného a bez externí služby provozované tímto projektem.
